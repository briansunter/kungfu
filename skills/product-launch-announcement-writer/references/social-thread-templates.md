# Social Media Thread Templates

Complete thread templates for X (Twitter) and Threads with post-by-post
breakdowns.

## X (Twitter) Thread Template

An 8-tweet thread optimized for engagement and shares.

**Tweet 1/8 - The Hook**

```twitter
🧵 1/8

I built [Product Name] to help [target audience] [solve problem].

[One-sentence hook about the problem - make it relatable]

#BuildInPublic #[Industry]
```

**Tweet 2/8 - The Problem**

```twitter
2/8

The problem: [describe specific pain point in 1-2 sentences]

I faced this constantly when [personal example]. It was
[frustrating/expensive/time-consuming].

[GIF/screenshot showing the problem]
```

**Tweet 3/8 - Market Gap**

```twitter
3/8

I looked for solutions but found [existing solution's weakness].

None of them quite hit the mark because [gap in market].

So I decided to build something better. 🛠️
```

**Tweet 4/8 - The Solution**

```twitter
4/8

Introducing [Product Name] 🎉

[Product Name] is a [category] that helps [target audience] [solve problem]
without [pain point].

[Short demo video or animated GIF]
```

**Tweet 5/8 - Features**

```twitter
5/8

Key features:

✅ [Feature 1] - [Benefit in 5 words]
✅ [Feature 2] - [Benefit in 5 words]
✅ [Feature 3] - [Benefit in 5 words]

Built with [tech stack] for [performance/quality/simplicity]
```

**Tweet 6/8 - Social Proof**

```twitter
6/8

Early results:

• [X] users in the first [week/month]
• "Best [tool] I've used" - @beta_tester
• [impressive metric: saves X hours, $Y cost, etc]

[Screenshot of testimonial or metric]
```

**Tweet 7/8 - CTA**

```twitter
7/8

Who is this for?

• [Target audience 1]
• [Target audience 2]
• [Target audience 3]

Try it free 👇

[link]
```

**Tweet 8/8 - Engagement**

```twitter
8/8

What's your experience with [problem]? Have you found a better solution?

I'd love to hear your thoughts! 👇

P.S. Follow me @yourhandle for more [topic] content

#[Industry] #SaaS #indiehackers #[OtherHashtag]
```

## Threads Thread Template

An 8-post thread optimized for conversational engagement.

**Post 1 - Hook + Visual**

```threads
[Image/Video: Product demo or eye-catching graphic]

I finally solved [problem] that's been bugging me for [time period].

Here's how I built [Product Name] 👇

[First post needs to be scroll-stopping!]
```

**Post 2 - The Problem**

```threads
The problem I kept running into: [specific pain point]

I tried [existing solutions] but they all [why they didn't work].

[Image: Screenshot of the problem or diagram]

Has anyone else dealt with this? 😅
```

**Post 3 - The "Aha" Moment**

```threads
Then I realized: [your insight about the solution]

What if there was a way to [desired outcome] without [pain point]?

That's when I started building [Product Name].
```

**Post 4 - The Solution**

```threads
So I built [Product Name] - a [category] that helps [target audience]
[solve problem].

[Video demo or GIF showing the product in action]
```

**Post 5 - Features**

```threads
Here's what it does:

• [Feature 1] - [brief benefit]
• [Feature 2] - [brief benefit]
• [Feature 3] - [brief benefit]

[Carousel images or screenshots showing each feature]

Built for [target audience] who want [desired outcome].
```

**Post 6 - Behind the Scenes**

```threads
Fun fact: It took [time] to build this using [tech stack].

Biggest challenge was [difficult part].

[Behind-the-scenes photo: workspace, code snippet, or design process]

#buildinpublic #indiehackers
```

**Post 7 - Early Feedback**

```threads
Early feedback has been amazing 🙌

"This is exactly what I needed!" - @username

[metrics: X users, Y hours saved, etc]

[Screenshot: Review or testimonial]
```

**Post 8 - CTA + Discussion**

```threads
Ready to try it out? Link in bio 👆

I'd love to hear your thoughts:

1. Have you faced [problem] before?
2. How did you solve it?
3. What would you add to [Product Name]?

Drop a comment below! 👇
```

## Thread Writing Tips

### X (Twitter) Thread Tips

- Use numbered format (1/8, 2/8) for thread navigation
- Keep each tweet under 280 characters
- Add "🧵" to first tweet to indicate thread
- End with a question to boost engagement
- Consider replying to your own thread with additional resources
- Post first tweet, then immediately add replies for remaining posts
- Pin the first tweet for 24 hours after posting

### Threads Thread Tips

- First post needs a strong visual (carousel works great)
- Write like you're talking to friends (more conversational than X)
- More emojis acceptable than X
- Focus on "behind the scenes" content
- Ask open-ended questions to drive discussion
- Link in bio strategy (put product link in bio, mention in posts)
- Timing: Weekends and evenings have higher engagement on Threads
